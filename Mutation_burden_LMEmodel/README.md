The code and input files provided here are for running a linear mixed effects model to assess the genome-wide mutation burden in Sjogren's Disease samples.

The following R packages were used for the mixed effects model: 
https://github.com/lme4/lme4/
https://github.com/runehaubo/lmerTestR

The raw number of mutations per sample has been adjusted by VAF and Depth. 

The number of mutations attributed to each SBS signature has been assigned using the Sigfit package, as described in the signature extraction code.
