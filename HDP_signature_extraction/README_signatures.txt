Signatures were extracted using the HDP package using no priors, as outlined in the "HDP_bySamle_noprior.R" script, as previously described in similar work. 

The signature components run across multiple sampling chains were extracted using the script "hdp_extract_chains_noprior_bySamp.R"

Signature deconvolution, reattribution, and postprocessing were done using the "hdp_noprior_sigfit_postprocess.R" script as previously described. 

Input files are provided.
